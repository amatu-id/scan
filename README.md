# Scan

Pemindai dokumen di browser, seperti aplikasi cam scanner. Foto dengan kamera HP atau pilih dari galeri, batas kertas dipotong otomatis, lalu hasilnya dirapikan seperti keluaran mesin scanner.

Situs: https://amatu-id.github.io/scan/

- Kamera langsung dengan garis batas dokumen real-time, ambil otomatis saat stabil, mode banyak halaman, lampu (bila didukung).
- Deteksi tepi kertas otomatis (Canny + Hough + area kertas), koreksi perspektif, sudut dapat digeser manual dengan kaca pembesar.
- Filter: Asli, Ajaib (latar putih bersih, warna tinta tetap), Tajam, Abu-abu, Hitam Putih; atur kecerahan, kontras, ketajaman, tebal teks.
- Edit halaman: pena, stabilo, teks, hapus (tip-ex), tutup area; urung/ulang.
- Halaman bisa ditambah, dihapus, diputar, diurutkan ulang.
- Unduh PDF (A4, F4, Letter, Legal, atau sesuai dokumen; margin; kualitas), JPG/PNG (satu per halaman atau ZIP), Bagikan, Cetak.
- Semua proses di perangkat; foto disimpan di IndexedDB browser, tidak diunggah ke server.
